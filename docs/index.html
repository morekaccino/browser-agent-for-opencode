How it works

The extension is the browser side. It talks to opencode V2 on your machine through a loopback bridge; opencode does the reasoning and tool calls. There is no developer server, no account, and no cloud relay.

Your prompts and the page context you include go to your local opencode service, then to the AI model provider you configured in opencode. Their privacy policy applies to that request.

Read-only workflows

Scheduled runs block native submissions, send/post-style controls, uploads, and JavaScript execution unless you opt in per workflow. Review the instructions before enabling one.

Requirements

  • Chrome 114 or newer.
  • opencode V2 installed and running on the same computer.
  • The browser bridge plugin installed in opencode. The extension’s setup screen can download it.
  • A model provider configured in opencode (hosted or local).

Privacy and safety

The extension has no analytics, ads, or data sale. It stores settings, workflows, and local connection credentials in Chrome’s local storage. You can clear that data from the extension settings or by uninstalling it.

The agent can read and change pages you ask it to operate on, and can run JavaScript through Chrome’s debugger. Only use it on accounts and pages you are allowed to automate.
